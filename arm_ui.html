PlayStation controller

No deadman: joints move only while you push a stick or button, and stop when you let go. After starting, release everything once before it responds. X = close gripper, O = open, L1 / L2 = rotate the wrist, D-pad ↑/↓ = speed scale. PS = hold all, Options = all limp and remote off. Joint style sticks: left X/Y = base/shoulder, right Y/X = elbow/wrist pitch.

Controller calibration

Maps this controller's sticks, triggers, buttons and D-pad, so the Remote tab works on any pad or OS. Takes about a minute. Remote mode must be off. Nothing moves the arm during this.

Joints in remote mode

Active = the stick drives it. Hold = torque on, stays put (still draws current). Limp = torque off, cool, but joints 4 and 5 will let the arm sag.

Raw controller input

To check the button mapping: move a stick or press a button and see which number changes.
